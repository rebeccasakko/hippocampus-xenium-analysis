# Review of the work so far

*Written 5 October 2026, reviewing the repository as of commit `c8fc321` (2 October 2026).*

This is a read-through of everything in the repository: the R code, the two protocol documents, and the saved figures. The raw data is not in the repository, so nothing was re-run. Each point below says whether it was **checked** (seen directly in the code or a figure, with the file and line) or **inferred** (a reasoned concern that still needs a test on the real data).

No analysis code was changed as part of this review.

---

## 1. The study in brief

- **Question:** how does gene activity in the mouse brain change 7 days after a traumatic brain injury (TBI)?
- **Injury model:** CHIMERA (a closed-head impact model).
- **Groups:** group i (`gi`) = TBI, 7 days post-injury; group ii (`gii`) = SHAM (same handling, no injury). *Source: Bec, 5 October 2026. The repository itself still calls the groups "blinded".*
- **Mice:** 3 per group, 6 in total: `gi_1_b`, `gi_2_d`, `gi_3_f` (TBI) and `gii_1_a`, `gii_2_c`, `gii_3_e` (SHAM).
- **Technology:** 10x Genomics Xenium with the ~5,000-gene mouse panel. It measures which genes are active in each cell *and* where each cell sits in the tissue slice.
- **Brain regions so far:** hippocampus and optic tract. The same six tissue sections are used for both; only the hand-drawn outline around the region changes. A third region is planned.

## 2. Short glossary

| Term | Plain meaning |
|---|---|
| Marker gene | A gene mostly active in one cell type, so it works like a name tag. |
| Module score | One number per cell summarising how active a set of marker genes is. |
| Argmax | "Pick the highest." Each cell gets the label whose score is highest. |
| Classification margin | How far the winning label was ahead of the runner-up. Small margin = shaky call. |
| Lasso / ROI | The hand-drawn outline of the brain region; only cells inside it are kept. |
| Composition | The percentage of cells that are each cell type. |
| Differential expression (DE) | Testing whether a gene is more or less active in TBI than SHAM. |
| Pseudobulk (DESeq2) | Adds up all cells of one type within each mouse, so every mouse counts once. Cautious; low power with 3 mice per group. |
| Wilcoxon (FindMarkers) | Treats every cell as a separate data point. Sensitive, but can produce false positives because cells from the same mouse are not independent ("pseudoreplication"). |
| padj | A p-value adjusted for running many tests at once. Below 0.05 is the usual cut-off for "significant". |
| Spillover | When a cell's outline accidentally captures RNA from a neighbouring cell. |
| Unclassified | Cells the pipeline declined to label because the evidence was too weak. |

## 3. How the pipeline works

The whole pipeline is the function `run_region_pipeline()` in `R/run_full_pipeline.R`, called once per brain region.

| Step | What happens | Where | Key settings (each is a decision) |
|---|---|---|---|
| 1. Load and clean | Read each mouse's Xenium output and drop cells with very little RNA. | `R/process_sample_template.R:7-9` | Keep cells with ≥10 RNA molecules and ≥5 genes. |
| 2. Keep the region | Keep only cells inside the hand-drawn outline. | `R/process_sample_template.R:11-16` | One outline file per mouse per region. |
| 3. Label every cell | Score each cell against ~13 to 20 marker sets and take the highest. Marker sets whose best gene is found in fewer than 0.5% of cells in that mouse are skipped. | `R/classify_atlas_index.R`, marker lists in `R/marker_panels.R` | Optic tract drops 4 marker sets that gave false hits there (see the classification protocol). |
| 4. Split into states | Astrocytes and microglia are split into "Active" or "Homeostatic" (resting); oligodendrocytes into "Mature" or "Precursor". | `R/classify_atlas_index.R:41-63` | Active astrocyte = Gfap, Serpina3n. Active microglia = Trem2, Cst7, Lpl. |
| 5. Drop shaky labels | The 15% of cells with the smallest margin become "Unclassified". | `R/apply_confidence_filter.R` | Optic tract only. |
| 6. Composition | Count cell types per mouse, plot TBI vs SHAM, t-test each cell type. | `R/build_composition_summary.R`, `R/plot_composition_barchart.R`, `R/build_stats_table.R` | Welch's t-test, then multiple-testing correction. |
| 7. Pictures for checking | UMAP (a 2D "map" where similar cells sit together) and tissue maps coloured by cell type. | `R/plot_umap_celltype.R`, `R/plot_spatial_celltype.R` | Display only; not used for labelling. |
| 8. Gene changes | Pseudobulk test on a short, literature-based gene list per cell type, plus Wilcoxon test on all genes. Heatmaps show one column per mouse. | `R/run_pseudobulk_de.R`, `R/run_wilcox_de.R`, `R/de_candidate_panels.R`, `R/plot_de_heatmap.R` | Positive fold change = higher in TBI (`run_pseudobulk_de.R:40`, `run_wilcox_de.R:24`). |
| 9. Spillover check | Checks whether a gene seen in one cell type really belongs to it or leaked in from neighbours. | `R/check_marker_spillover.R` | Used once, for Gfap in microglia (judged real). |

## 4. Results so far

### Hippocampus (written up in `protocols/differential_expression_protocol.md`)

- **Cell-type composition:** no cell type differed significantly between groups. The closest were hippocampal pyramidal neurons (p = 0.066) and homeostatic astrocytes (p = 0.078). These look like p-values *before* correction for testing 16 cell types (`R/build_stats_table.R` header), so after correction they would be weaker. *Inferred; worth confirming.*
- **Gene changes:**
  - **P2ry13 in microglia** is significant under both the cautious and the sensitive test. This is the strongest hippocampus result.
  - **Id2 in dentate gyrus granule cells** is significant with Wilcoxon and just misses with pseudobulk (padj 0.056), in the same direction.
  - Wilcoxon also flags 24 dentate gyrus, 9 astrocyte, 4 microglia and 1 interneuron genes, but most are not backed up by the cautious test.
  - The protocol does not say whether these genes went **up or down** in TBI. Now that the groups are known, that should be added.
- Hippocampus figures are not saved in the repository.

### Optic tract (figures in `outputs/optic_tract/`, not written up anywhere yet)

Read from the saved figures (**checked** by eye; the exact numbers were not saved as tables):

- **Composition** (`composition_barchart.png`): mature oligodendrocytes are the largest group (~23-25%), as expected for white matter. About 18% (TBI) and 23% (SHAM) of cells are Unclassified; one SHAM mouse is near 35%. TBI looks higher for peripheral macrophages (4.4% vs 1.4%), neutrophils (4.2% vs 1.2%) and B cells (4.5% vs 0%), and lower for homeostatic astrocytes (0.7% vs 2.8%). **None of these have been tested yet**, and several rest on one or two mice.
- **Microglia, pseudobulk** (`pseudobulk_heatmap_microglia.png`): **Trem2, Cst7 and Lpl are clearly higher in all three TBI mice** (strongest significance level), and the heatmap's own clustering separates TBI from SHAM without being told the groups. This "activated microglia" gene pattern fits published reports that CHIMERA injures the optic tract. P2ry13 and Tmem119 are also higher in TBI, which is a little surprising because these usually *fall* when microglia activate.
- **Microglia, Wilcoxon** (`wilcox_heatmap_microglia.png`): ~26 genes. Immune and activation genes (Cd68, Trem2, C3ar1, Aif1, Csf1r, Grn, Ptprc and others) are higher in TBI. A few lower in TBI (Cnp, Cpox, Myo1d, Dpysl2) are oligodendrocyte genes; see point F below.
- **Astrocytes:** the pseudobulk gene list shows no group pattern. Wilcoxon finds Serpina3n and S1pr3 higher in TBI, Prodh and Fam20a lower; mice cluster by group.
- **Mature oligodendrocytes (Wilcoxon):** C4b, Gfap and Serpina3n higher in TBI; Mog, Psat1, Tsc22d3 and Dpysl2 lower.
- **Oligodendrocyte precursors (Wilcoxon):** only Gfap.
- Across nearly every heatmap, TBI mouse `gi_1_b` shows the strongest change. Injury severity can vary from mouse to mouse; with 3 mice, one strongly injured mouse can carry a result.

## 5. What is working well

- **Every decision is written down with a date and a reason**, including the dead ends. This is unusually good and makes the work easy to check and to reverse.
- **Two gene-change methods reported side by side**, with an honest explanation of the pseudoreplication risk and a citation (Squair et al., 2021).
- **Heatmaps show one column per mouse**, never per cell, and the clustering is left free so it can confirm or fail to confirm the group split.
- **Built-in sanity checks** (Purkinje cells should be ~0% outside the cerebellum) and a reusable spillover check.
- **Careful fixes already made**, for example making sure a cell type absent from one mouse is counted as 0% instead of silently dropped (`R/build_composition_summary.R:4-19`).
- **Decisions were made while blinded** to which group was TBI. That protects against unconscious bias.

## 6. Issues found

Ranked by how much they could change a result. "Decision" means Bec should choose before anything is changed.

### Could change results

**A. The "drop shaky labels" step is not applied to the gene-change tests.** *Checked.*
The filter only rewrites the `cell_type` column (`R/apply_confidence_filter.R:2-6`). Both gene-change functions select cells by a different column, `atlas_identity` (`R/run_pseudobulk_de.R:16`, `R/run_wilcox_de.R:16`). So in the optic tract, the ~15% of cells shown as "Unclassified" in the composition chart are still included in the astrocyte and microglia gene tests.
*Fix options (decision):* run the gene tests on filtered labels, or deliberately keep them unfiltered and say so in the protocol.

**B. The hippocampus code does not match what the protocol says was done.** *Checked.*
The protocol says the hippocampus uses a fixed `margin > 1` filter. But the hippocampus call in `R/run_full_pipeline.R:252-254` applies no filter at all, and `apply_confidence_filter()` is not called anywhere else. Re-running the script would therefore probably not reproduce the hippocampus results already shown. *Inferred.*
*Needs:* Bec to confirm which settings produced the hippocampus figures, so the code can be made to match.

**C. Some tested genes were also used to decide which cells count as that cell type.** *Checked (gene lists); effect inferred.*
Microglia are picked partly by P2ry13 and Tmem119 (`R/marker_panels.R:4`), and those same genes are then tested between groups (`R/de_candidate_panels.R:18`). The same is true for Aldh1l1 and Sox9 in astrocytes. In plain terms: if you choose cells *because* they have a lot of a gene, then compare that gene between groups, the selection itself can create or hide a difference. This touches the strongest hippocampus result (P2ry13). It isn't necessarily wrong, but a reviewer will likely ask.
*Suggested check:* classify microglia without P2ry13 in the marker set and see whether the P2ry13 result holds.

**D. Labelling scores are standardised within each mouse.** *Checked (`R/classify_atlas_index.R:28`); effect inferred.*
Each mouse's cells are compared with that mouse's own average before picking the winning label. This helps cancel technical differences between tissue sections, but it can also shrink real differences. For example, if a TBI mouse truly has many more microglia, its microglia scores are compared against a higher average, so some borderline microglia may lose their label. This could make composition differences look smaller than they are.
*Suggested check:* standardise across all six mice together and compare the composition charts.

**E. The 0.5% detection rule switches whole cell types on or off per mouse.** *Checked (`R/classify_atlas_index.R:12-20`).*
If a cell type's best marker is rare in one mouse, that cell type is skipped *for that mouse only*. The code comments say B cells were absent in all three SHAM mice (`R/build_composition_summary.R:16-18`). That could be real, or it could be the rule switching B cells off in those mice. The printed warnings from the run would tell which.

**F. Some astrocyte genes show up as "changed" in every optic tract cell type.** *Checked (figures); cause inferred.*
Gfap and Serpina3n are classic reactive-astrocyte genes. They come out as higher in TBI in microglia, mature oligodendrocytes and oligodendrocyte precursors as well as astrocytes. Likewise, oligodendrocyte genes (Cnp, Dpysl2) appear in the microglia list. One likely explanation is spillover: after injury, nearby astrocytes make much more Gfap, and some of it lands inside neighbouring cells' outlines. The earlier Gfap check compared Gfap-positive with Gfap-negative microglia; it did not test whether the TBI-vs-SHAM difference itself comes from leakage.
*Suggested check:* re-run `check_marker_spillover()` for Serpina3n and Gfap in oligodendrocytes, and compare TBI with SHAM.

### Worth tightening

**G. Composition statistics.** *Checked (`R/build_stats_table.R`).* A separate t-test per cell type on percentages, with 3 mice per group. The percentages are linked (they add up to 100%, so one going up pushes others down), and "Unclassified" is tested as if it were a cell type. There are methods designed for this kind of data (for example `propeller` in the `speckle` R package). Optic tract statistics have not been run or saved. *Decision.*

**H. The 15% filter is shared across both groups.** *Checked (`R/apply_confidence_filter.R:28-35`).* The cut-off comes from all six mice pooled together, so if one group's cells are labelled less confidently, more of that group is removed. One SHAM mouse (`gii_1_a`, probably, from the sample-1 symbol) has ~35% Unclassified versus ~15-20% for the others. That mouse's data quality is worth a look (cells per outline, RNA molecules per cell).

**I. Low quality-control floor.** *Checked (`R/process_sample_template.R:4`).* Keeping cells with as few as 10 RNA molecules is lenient for a 5,000-gene panel. A stricter comparison was run for the hippocampus on 29 September (`R/build_composition_summary.R:47-50`), but its outcome isn't written down. *Decision.*

**J. "Active" astrocytes in the optic tract may simply be white-matter astrocytes.** *Inferred.* White-matter astrocytes normally have high Gfap even without injury. That fits the chart, where "Active" outnumbers "Homeostatic" in *both* groups. "Active" in the optic tract may not mean "reacting to injury".

**K. The state split has no "can't tell" option.** *Checked (`R/classify_atlas_index.R:46`).* A cell with little signal from either state's genes is still forced into one, and exact ties go to Homeostatic/Precursor.

**L. One TBI mouse carries much of the signal.** *Checked (figures).* See section 4. Worth stating openly in any write-up.

### Record-keeping and reproducibility

**M. The oligodendrocyte figures can't be reproduced from the script.** *Checked.* The optic tract pipeline only lists astrocytes and microglia (`R/run_full_pipeline.R:244-247`), there is no oligodendrocyte gene list in `R/de_candidate_panels.R`, and the oligodendrocyte heatmaps were split by state (which needs `identity_col = "cell_type"`). They were likely made by hand in the console.

**N. Result tables are not saved, only pictures.** All `.csv` files are excluded from git (`.gitignore`), so the gene lists, fold changes and p-values behind each figure are not on record. Saving them as `.tsv` files in `outputs/` would fix this.

**O. No record of software versions.** There's no saved `sessionInfo()` or `renv` lock file, and data paths point to an external drive and a Desktop. Seurat in particular changes behaviour between versions (for example, `run_pseudobulk_de.R:26` relies on Seurat 5 turning `_` into `-` in sample names).

**P. Documentation is behind the work.** The README and DE protocol cover the hippocampus only; there are no optic tract results; the groups are still described as blinded; the hippocampus figures are missing.

**Q. Small tidy-ups.** Three loose draft images in the top folder (`Rplot.png`, `optic_tract_composition_barchart.png`, `optic_tract_composition_barchart_final.png`). The loading function is still called `process_hippocampus_sample()` although it serves every region. `R/check_marker_spillover.R` loads `tidyverse`, which isn't in the pipeline's package list. `R/build_stats_table.R:34` uses `cur_data()`, which newer dplyr versions warn about.
