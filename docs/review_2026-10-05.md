## 1. The study in brief

- **Question:** how does gene activity in the mouse brain change 7 days after a traumatic brain injury (TBI)? It began as "do astrocytes express Tau (*Mapt*)?" and grew into region-wide cell-type and gene-change analysis. *(Notes)*
- **Injury model:** CHIMERA (a closed-head impact model).
- **Groups:** group i (`gi`) = TBI, 7 days post-injury; group ii (`gii`) = sham (same handling, no injury). The analysis ran blinded and was **unblinded on 30 September 2026**. *(Notes; also confirmed by Bec in this project.)* The repository text still describes the groups as blinded.
- **Mice:** 3 per group: `gi_1_b`, `gi_2_d`, `gi_3_f` (TBI) and `gii_1_a`, `gii_2_c`, `gii_3_e` (sham).
- **Technology:** 10x Genomics Xenium, **Xenium Prime 5K Mouse Pan Tissue & Pathways panel** (~5,000 genes). It measures which genes are active in each cell *and* where each cell sits in the tissue slice.
- **Brain regions:** hippocampus and optic tract so far. The same six tissue sections are used for both; only the hand-drawn outline changes. A third region is planned.
- **Goal:** submit for publication by the end of 2026, then hand the repository to a biostatistician. The current plan is two papers: a methods paper on the pipeline itself, and a separate B cell / immune finding handed to someone with immunology expertise. *(Notes)*

## 2. Short glossary

| Term | Plain meaning |
|---|---|
| Marker gene | A gene mostly active in one cell type, so it works like a name tag. |
| Module score | One number per cell summarising how active a set of marker genes is. |
| Argmax | "Pick the highest." Each cell gets the label whose score is highest. |
| Classification margin | How far the winning label was ahead of the runner-up. Small margin = shaky call. |
| Lasso / ROI | The hand-drawn outline of the brain region; only cells inside it are kept. |
| Composition | The percentage of cells that are each cell type. |
| Differential expression (DE) | Testing whether a gene is more or less active in TBI than sham. |
| Pseudobulk (DESeq2) | Adds up all cells of one type within each mouse, so every mouse counts once. Cautious; low power with 3 mice per group. |
| Wilcoxon (FindMarkers) | Treats every cell as a separate data point. Sensitive, but can produce false positives because cells from the same mouse are not independent ("pseudoreplication"). |
| Mixed-effects model | A test that uses every cell but knows which mouse each cell came from, so it avoids pseudoreplication. FLASH-MM is one. |
| padj | A p-value adjusted for running many tests at once. Below 0.05 is the usual cut-off for "significant". |
| Spillover | When a cell's outline accidentally captures RNA from a neighbouring cell. |
| Unclassified | Cells the pipeline declined to label because the evidence was too weak. |

## 3. How the pipeline works

The whole pipeline is the function `run_region_pipeline()` in `R/run_full_pipeline.R`, called once per brain region.

| Step | What happens | Where | Key settings (each is a decision) |
|---|---|---|---|
| 1. Load and clean | Read each mouse's Xenium output and drop cells with very little RNA. | `R/process_sample_template.R:7-9` | Keep cells with ≥10 RNA molecules and ≥5 genes. |
| 2. Keep the region | Keep only cells inside the hand-drawn outline. | `R/process_sample_template.R:11-16` | One outline file per mouse per region. |
| 3. Label every cell | Score each cell against every marker set and take the highest. Marker sets whose best gene is found in fewer than 0.5% of cells in that mouse are skipped. | `R/classify_atlas_index.R`, marker lists in `R/marker_panels.R` | Marker sets were built from the Allen Institute mouse brain atlas (Yao et al., 2023) and checked against the 5K panel. Optic tract drops 4 sets that gave false hits there. |
| 4. Split into states | Astrocytes and microglia are split into "Active" or "Homeostatic" (resting); oligodendrocytes into "Mature" or "Precursor". | `R/classify_atlas_index.R:41-63` | Active astrocyte = Gfap, Serpina3n. Active microglia = Trem2, Cst7, Lpl. |
| 5. Drop shaky labels | Optic tract: the 15% of cells with the smallest margin become "Unclassified". Hippocampus: BAM cells with margin ≤ 1 become "Unclassified" *(notes; that code is not in the repository, see issue B)*. | `R/apply_confidence_filter.R` | Region-specific because margins shrink when more marker sets compete. |
| 6. Composition | Count cell types per mouse, plot TBI vs sham, t-test each cell type. | `R/build_composition_summary.R`, `R/plot_composition_barchart.R`, `R/build_stats_table.R` | Welch's t-test, then Benjamini-Hochberg correction. |
| 7. Pictures for checking | UMAP (a 2D "map" where similar cells sit together) and tissue maps coloured by cell type. | `R/plot_umap_celltype.R`, `R/plot_spatial_celltype.R` | Display only; not used for labelling. |
| 8. Gene changes | Pseudobulk test on a short, literature-based gene list per cell type, plus Wilcoxon test on all genes. Heatmaps show one column per mouse. | `R/run_pseudobulk_de.R`, `R/run_wilcox_de.R`, `R/de_candidate_panels.R`, `R/plot_de_heatmap.R` | Positive fold change = higher in TBI (`run_pseudobulk_de.R:40`, `run_wilcox_de.R:24`). |
| 9. Spillover check | Checks whether a gene seen in one cell type really belongs to it or leaked in from neighbours. | `R/check_marker_spillover.R` | Used once, for Gfap in microglia (judged real). |

## 5. Results so far

### Hippocampus

- **Cell-type composition:** nothing is significant after correction across 16 categories (all p_adj ≥ 0.614). The closest raw p-values were hippocampal pyramidal neurons (0.066) and homeostatic astrocytes (0.078). Active microglia p = 0.51. *(Notes)*
- **Quality checks:** Unclassified ~3.8-6.1%, Purkinje ~0%, BAM under 1% after the fix. *(Notes)*
- **Gene changes** (`protocols/differential_expression_protocol.md`):
  - **P2ry13 in microglia** is significant under both the cautious and the sensitive test. This is the strongest hippocampus result.
  - **Id2 in dentate gyrus granule cells** is significant with Wilcoxon and just misses with pseudobulk (padj 0.056), in the same direction.
  - Wilcoxon also flags 24 dentate gyrus, 9 astrocyte, 4 microglia and 1 interneuron genes, but most are not backed up by the cautious test.
  - The protocol does not say whether these genes went **up or down** in TBI.
- **The original Tau question:** *Mapt* is in the astrocyte gene-test list, and the astrocyte pseudobulk result was null, so Tau did not change significantly in hippocampal astrocytes. *(Checked, from the protocol's results table.)* How often astrocytes express *Mapt* at all is not written down.

### Optic tract (provisional: old outlines, to be redone)

- **Cells captured per mouse are small and uneven:** TBI 620 / 692 / 612; sham 425 / 602 / 168. `gii_3_e` is a clear low-count outlier. *(Notes)* At 168 cells, one cell is 0.6% of the total.
- **Composition** (`outputs/optic_tract/composition_barchart.png`, checked by eye): mature oligodendrocytes are the largest group (~23-25%). About 18% (TBI) and 23% (sham) of cells are Unclassified, mostly by design (the 15% filter). TBI looks higher for peripheral macrophages (4.4% vs 1.4%), neutrophils (4.2% vs 1.2%) and **B cells (2.78-7.74% in TBI vs 0% in all three sham mice)**. None of these have been tested.
- **Microglia, pseudobulk:** **Trem2, Cst7 and Lpl are clearly higher in all three TBI mice**, and the heatmap's own clustering separates TBI from sham without being told the groups. This "activated microglia" pattern fits published reports that CHIMERA injures the optic tract. P2ry13 and Tmem119 are also higher in TBI, which is surprising because these usually *fall* when microglia activate.
- **Microglia, Wilcoxon:** ~26 genes; immune and activation genes (Cd68, Trem2, C3ar1, Aif1, Csf1r, Grn, Ptprc and others) higher in TBI. A few oligodendrocyte genes (Cnp, Dpysl2) are lower; see issue F.
- **Astrocytes:** the pseudobulk list (including *Mapt*) shows no group pattern. Wilcoxon finds Serpina3n and S1pr3 higher in TBI, Prodh and Fam20a lower.
- **Mature oligodendrocytes (Wilcoxon):** C4b, Gfap and Serpina3n higher in TBI; Mog, Psat1, Tsc22d3 and Dpysl2 lower. The notes call this "real signal".
- **Oligodendrocyte precursors (Wilcoxon):** only Gfap (log2 fold change 1.43, padj 0.004). Bec already judged this probable spillover and left it out of the presentation. *(Notes)*
- **GABAergic interneurons:** no significant genes (too few cells). *(Notes)*
- TBI mouse `gi_1_b` shows the strongest change in nearly every heatmap.

### Current thread: B cells and Cd22 *(Notes)*

The focus has moved to the optic tract B cell signal and the gene Cd22. The next planned step is raw and normalised Cd22 counts per mouse inside the new outlines, before full labelling. The notes frame Xenium here as a screening tool: n = 3 cannot carry a B cell claim alone, and it would need more animals and an independent method (flow cytometry or tissue staining). The detailed Cd22 numbers from the last session were lost and need re-checking.

## 6. What is working well

- **Every decision is written down with a date and a reason**, including the dead ends. This is unusually good and makes the work easy to check and to reverse.
- **The defensible choice was taken over the convenient one.** Active microglia gave p = 0.089 with a flawed BAM marker set and p = 0.51 with the corrected one; the corrected one was adopted. *(Notes)*
- **Two gene-change methods reported side by side**, with an honest explanation of the pseudoreplication risk (Squair et al., 2021).
- **Heatmaps show one column per mouse**, never per cell, and the clustering is left free so it can confirm or fail to confirm the group split.
- **Built-in sanity checks** (Purkinje ~0% outside the cerebellum), a reusable spillover check, and quality-control sensitivity already tested.
- **Careful fixes already made**, for example counting an absent cell type as 0% instead of silently dropping it (`R/build_composition_summary.R:4-19`).
- **Decisions were made blind** until 30 September, and rules are applied the same way to both groups.

## 7. Issues found

Ranked by how much they could change a result. "Decision" means Bec should choose before anything is changed. Letters are kept from the first version of this review so earlier references still work; T, U and V are new.

### Could change results

**B. The hippocampus results cannot be reproduced from the script.** *Checked against the notes.*
Four things differ between what was reported and what `run_region_pipeline()` would do today:
1. The BAM-only margin > 1 filter is not in the repo and is not applied.
2. The script now scores 20 marker sets, not the 13 the results used. Because margins shrink when more sets compete (the repo's own finding, `R/apply_confidence_filter.R:15-27`), the margin > 1 threshold validated at 13 sets would not carry over anyway.
3. It is unclear whether the adopted results used the baseline or the strict quality-control regime.
4. The `gi_3_f` outline file name in the script doesn't match the file on the Desktop.

*Needs:* the `apply_bam_confidence_filter` and `audit_detection` code added to the repo, and a decision on the hippocampus marker list (see section 8).

**C. Some tested genes were also used to decide which cells count as that cell type.** *Checked (gene lists); effect inferred.*
Microglia are picked partly by P2ry13 and Tmem119 (`R/marker_panels.R:4`), and those same genes are then tested between groups (`R/de_candidate_panels.R:18`). The same is true for Aldh1l1 and Sox9 in astrocytes. In plain terms: if you choose cells *because* they have a lot of a gene, then compare that gene between groups, the selection itself can create or hide a difference. The notes already apply this reasoning to Gfap ("not in the astrocyte classification panel, so there is no circularity"); P2ry13, the strongest hippocampus result, does not pass that same test.
*Suggested check:* classify microglia without P2ry13 in the marker set and see whether the P2ry13 result holds.

**T. Cd22 is also a microglia gene.** *Inferred.*
Cd22 is in the B cell marker set (`R/marker_panels.R:24`), but microglia also make Cd22 (Pluvinage et al., 2019, *Nature*). The optic tract microglia are clearly activated in TBI. Two consequences:
- If B cell calls are driven by Cd22 alone, they could be microglia. This is the same "one gene doing all the work" pattern already found for Pou3f1, Prox1 and Foxj1.
- Raw Cd22 counts per mouse (the planned next step) would mix B cell and microglia Cd22, so a TBI increase would not by itself point to B cells.

*Suggested check:* before relying on Cd22 counts, run the same per-gene detection check used for the excluded marker sets on the B cell calls, and count Cd22 separately inside microglia.

**D. Labelling scores are standardised within each mouse.** *Checked (`R/classify_atlas_index.R:28`); effect inferred.*
Each mouse's cells are compared with that mouse's own average before picking the winning label. This helps cancel technical differences between tissue sections, but it can also shrink real differences. If a TBI mouse truly has many more microglia, its microglia scores are compared against a higher average, so some borderline microglia may lose their label.
*Suggested check:* standardise across all six mice together and compare the composition charts.

**E. The 0.5% detection rule switches whole cell types on or off per mouse.** *Checked (`R/classify_atlas_index.R:12-20`).*
If a cell type's best marker is rare in one mouse, that cell type is skipped *for that mouse only*. The notes give a clear example of how fragile this is: strict quality control removed only 0.1-0.2% of cells, yet BAM in `gi_2_d` went from 0 cells to 256 because its detection rate crossed the line. The cut-off also means different things in different mice: about 3 cells in a 650-cell optic tract outline, but 1 cell in `gii_3_e`'s 168. The B cell result (0% in every sham mouse) could be real or could be this switch; the printed warnings from the run would tell which.

**F. Some astrocyte genes show up as "changed" in every optic tract cell type.** *Checked (figures); cause inferred.*
Gfap and Serpina3n come out higher in TBI in microglia, mature oligodendrocytes and precursors as well as astrocytes, and oligodendrocyte genes (Cnp, Dpysl2) appear in the microglia list. Bec already treated the precursor Gfap hit as probable spillover. The same reasoning should apply to the Gfap hits in mature oligodendrocytes and microglia. The direction of leakage isn't obvious either: the notes say Serpina3n is mostly made by oligodendrocytes in white matter, so the *astrocyte* Serpina3n hit may be the borrowed one.
*Suggested check:* run `check_marker_spillover()` for Gfap and Serpina3n in each cell type, comparing TBI with sham.

### Worth tightening

**A. The "drop shaky labels" step is not applied to the gene-change tests.** *Checked.*
The filter only rewrites the `cell_type` column (`R/apply_confidence_filter.R:2-6`), while both gene-change functions select cells by `atlas_identity` (`R/run_pseudobulk_de.R:16`, `R/run_wilcox_de.R:16`). The notes say only ~1-6% of optic tract astrocyte and microglia calls flip at this threshold, so the effect there is probably small, but the composition chart and gene tests are using different cell sets. *Decision.*

**U. Optic tract outlines capture few and unequal cell numbers.** *Notes.* 168-692 cells per mouse, with fewer in the sham outlines. Bec already lists this as a limitation. It makes optic tract percentages noisy and links to issue E. Pseudobulk for a cell type making up 10% of `gii_3_e` rests on about 17 cells.

**V. The outline reader assumes one shape per file.** *Checked (`R/process_sample_template.R:11-13`); risk inferred.* All rows are read as a single polygon and the `Selection` column is ignored. If a file holds more than one shape (Xenium Explorer can export several, and the new border-inclusive optic tract outlines might), the shapes would be joined into one wrong outline. Check the number of distinct `Selection` values in each new file before use. The new files are named `GI-1` to `GII-3`, so they also need the sample mapping confirmed with Sakthi. *(Notes)*

**G. Composition statistics.** *Checked (`R/build_stats_table.R`).* A separate t-test per cell type on percentages, with 3 mice per group. The percentages are linked (they add up to 100%), and "Unclassified" is tested as if it were a cell type. Methods built for this exist (for example `propeller` in the `speckle` R package). Optic tract statistics have not been run. *Decision.*

**H. The 15% filter is one cut-off for both groups.** *Checked (`R/apply_confidence_filter.R:28-35`).* Using one shared cut-off follows the "treat both groups the same" rule, which is right. Still, one sham mouse (`gii_1_a`) has ~35% Unclassified versus ~15-20% for the others, so report how many cells the filter removes from each mouse.

**I. Quality-control regime.** *Notes.* Strict quality control changes composition very little, so it is not driving results. The remaining step is to pick one regime and make it the pipeline's setting. *Decision.*

**J. "Active" astrocytes in the optic tract are not a reactivity readout.** *Notes confirm.* Gfap and Serpina3n are compromised as state markers in white matter. The chart still shows Active and Homeostatic astrocyte bars for the optic tract, and the protocol doesn't record the limitation.

**K. The state split has no "can't tell" option.** *Checked (`R/classify_atlas_index.R:46`).* A cell with little signal from either state's genes is still forced into one, and exact ties go to Homeostatic/Precursor.

**L. One TBI mouse carries much of the signal.** *Checked (figures).* Worth stating openly in any write-up.

### Record-keeping and reproducibility

These matter more given the planned methods paper and the biostatistician handoff.

**M. Console-only analyses.** The optic tract gene tests for oligodendrocytes and interneurons aren't in the script, and there's no oligodendrocyte gene-test list in `R/de_candidate_panels.R`.

**N. Result tables are not saved, only pictures.** All `.csv` files are excluded from git, so the numbers behind each figure are not on record. Saving them as `.tsv` files in `outputs/` would fix this.

**O. No record of software versions.** No saved `sessionInfo()` or `renv` lock file. Seurat changes behaviour between versions (for example, `run_pseudobulk_de.R:26` relies on Seurat 5 turning `_` into `-` in sample names).

**P. Documentation is behind the work.** README and DE protocol cover the hippocampus only, still say "blinded", and say "~13" marker sets. There are no optic tract results and no hippocampus figures.

**Q. Small tidy-ups.** Three loose draft images in the top folder. The loading function is still called `process_hippocampus_sample()` although it serves every region. `R/check_marker_spillover.R` loads `tidyverse`, which isn't in the pipeline's package list. `R/build_stats_table.R:34` uses `cur_data()`, which newer dplyr versions warn about. The pipeline should save each mouse's labelled object, not only the merged one.
